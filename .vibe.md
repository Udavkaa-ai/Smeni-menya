Сменимся — mobile-first PWA для двух конкретных пользователей (Светы и Марии), чтобы делить дежурства по уходу за мамой: каждая отмечает только свою занятость, дежурство получается по умолчанию.

Стек: React + Vite + Zustand + React Query на фронте, Node.js (Express) + PostgreSQL + ws на бэке, Web Push (VAPID), деплой на Railway (frontend nginx проксит /api и /ws через приватную IPv6-сеть).

Сейчас в фокусе: упрощённая модель «занятость + описание» (дежурство больше не вводят явно), вертикальные полоски занятости слева/справа карточки и горизонтальная полоса «кто с мамой» в одну строку с датой, iOS-style wheel-пикер для времени, поддержка ночных смен через полночь, persistent in-app уведомления с обязательным подтверждением получателем, автоматическое определение конфликтов «обе заняты» и push-уведомление обеим.

Архитектура: жёстко вшито двое юзеров SVETA/MARIA (не SaaS), JWT-логин с фикспаролями из env, реалтайм через WebSocket с reconnect-backoff, на каждый Railway-билд бампится APP_DATA_VERSION и клиент сам стирает старый кеш + SW при первом заходе, миграции схемы идемпотентны при каждом старте бэка.
